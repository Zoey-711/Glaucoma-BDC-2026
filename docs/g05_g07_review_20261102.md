## 实现与边界

原研究入口将许可固定为 Apache-2.0，因而不能诚实地加载声明 MIT 的 Swin 权重。入口现在仅接受 Apache-2.0 / MIT，并要求配置与已审核清单的许可一致；旧 Apache 清单的缺省语义保留。未删除权重、来源、模型卡、许可证哈希或非医学审核检查；不接受 NC 或未知许可。新增回归覆盖许可不一致、MIT 缺省字段、NC、再分发未批准及旧清单兼容性。

Swin 原始权重包含旧版 attention mask / relative-position index 缓存。加载时采用 timm 官方 checkpoint_filter_fn，按目标分辨率重建这些非训练参数缓存，随后仍以 strict=True 校验所有可训练参数；原始权重文件及 SHA256 均未改动。新增回归证明旧缓存可以兼容，而真实参数缺失或未知参数仍会失败。

G05/G07 只有在具体权重核验后才改为 PENDING，配置 identity 重新计算。新矩阵 `configs/research/g05_g07_20261102.yaml` 仅安排 G05/GPU3、G07/GPU4，运行前再次检查 GPU 空闲。训练使用原 384 输入、batch32、seed42、BCE、AdamW、30轮上限及5轮早停；不修改官方 Train/Val 划分，不使用 Test。

运行前须通过加载审核权重的真实 batch32 AMP 合成反向传播检查，并固定本次代码 commit。运行结果保存到独立 results/G05 和 results/G07 目录，不覆盖 H03 或其他历史结果。实际结果和当前进程状态以运行工件为准。

上述是权重来源与工程核验，不代替主办方对最终参赛材料的审查。H04、G06/G08 等未在本任务中启动；不顺带解除其他配置的 BLOCKED。
